Circular Queue Using Linked List

Project By: Manjit Rabha

📌 About the Project

This project implements a Circular Queue using a Linked List. A circular queue is a linear data structure that follows the FIFO (First In, First Out) principle. In a circular queue, the last node is connected back to the first node, forming a circle.

This project demonstrates how circular queue operations work using linked list concepts.

✨ Features

- Insert: Add an element to the queue.
- Delete: Remove an element from the queue.
- Search: Find an element in the queue.
- Display: Show all elements in the queue.
- Circular Structure: The last node points back to the first node.
- Dynamic Memory: Nodes are created as needed.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

⚙️ Operations

1. Insert: Adds a new element at the rear of the queue.
2. Delete: Removes an element from the front of the queue.
3. Search: Checks whether a particular element exists in the queue.
4. Display: Displays the current elements of the queue.

📚 Data Structure

The project uses a linked list where each node contains:

- Data: Stores the element.
- Next: Stores the reference to the next node.

The last node points to the first node, maintaining the circular structure.
